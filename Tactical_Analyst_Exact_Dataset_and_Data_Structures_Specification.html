1. Executive Data Architecture & Lifecycle

Tactical Analyst manages football data across six distinct phases: ingestion, validation, normalization, feature calculation, relational persistence, and presentation rendering. The architecture strictly adheres to the four Core-4 Data Integrity Rules:

  • Core-4 Rule 8 (Raw vs. Derived Separation): Raw observational counts (e.g., passes attempted, raw tackles, spatial touch coordinates) are strictly preserved and separated from derived mathematical rates (per-90 rates, passing accuracy %, expected goals $xG$).
  • Core-4 Rule 10 (Canonical Identity Resolution): Every player is assigned a permanent canonical identifier (e.g. p_cole_palmer, p_nicolas_jackson) that unifies longitudinal multi-match appearances and photographic avatar assets across CSV and JSON inputs.
  • Core-4 Rule 11 (Match Metadata Integrity): Every match is keyed by an industry-standard compound identifier match_YYYYMMDD_home_away (e.g. match_20240928_che_bha) accompanied by immutable calendar dates and venue classification.
  • Core-4 Rule 12 (Pitch Coordinate Normalization): All spatial pitch coordinates are normalized to a uniform 0.0 to 100.0 percentage grid ($X \in [0.0, 100.0]$ length, $Y \in [0.0, 100.0]$ width).

2. Relational Database Schema (SQL DDL & SQLite Storage)

Tactical Analyst maintains relational persistence via an embedded SQLite database (`data/football_analyzer.db`) for local, zero-latency desktop operation, matching an enterprise PostgreSQL / Supabase DDL schema (`backend/database/schema.sql`). Foreign key constraints are actively enforced via PRAGMA foreign_keys = ON;.

2.1 The 8 Persistent Relational Tables

3. Pydantic Validation Engine & Business Rules

Every imported match payload passes through strict Pydantic V2 models defined in `backend/analysis/validation/schemas.py`. Any schema violation, lineup mismatch, or mathematical inconsistency immediately raises an HTTP 422 Unprocessable Entity error and aborts persistence without corrupting the database.

3.2 Enforced Invariants and Business Rules

Invariant Name Validation Rule Logic Error Handling Behavior
Starting XI Invariant len([p for p in players if p.is_starter]) == 11 Raises ValueError if starter count ≠ 11 for complete squad sheets.
Goalkeeper Invariant len([p for p in starters if p.primary_position == 'GK']) == 1 Rejects squad sheet if starting goalkeeper count is 0 or > 1.
Referential Integrity ev.player_id in {p.player_id for p in players} Rejects spatial event stream if any action points to an unlisted player.
Scoreline Coherence sum(p.goals for p in players) ≤ match.score_team Prevents player goal counts from exceeding official match goals.
Mathematical Bounds passes_completed ≤ passes_attempted
tackles_won ≤ tackles_attempted
shots_on_target ≤ shots_total		 Enforces natural physical limits; auto-corrects or raises validation errors.

7. Mathematical Formulas & Derived Features

Tactical Analyst implements transparent, reproducible mathematical equations for all derived features. Every formula is publicly documented and strictly separates raw data from calculated rates.

7.1 Per-90 Normalization

Playing Time Rate Normalization
Metricp90 = Raw Accumulated Metric Minutes Played × 90.0
Computed in backend/analysis/player/metrics.py. If minutes played is 0, the metric returns 0.0. Players with < 270 minutes across the season are flagged with a low-sample badge.

7.2 Volume-Weighted Season Rates

Season Accuracy Percentage
Season Pass Accuracy % = ∑ Passes Completedm ∑ Passes Attemptedm × 100.0
Applies identically to Tackle Success %, Duel Win %, and Shot Accuracy %. Never averages per-match percentages.

7.3 Proportional Match Contribution Score

Treemap & Packed Bubble Area Sizing
Score = (4.0 · G) + (2.5 · A) + (1.2 · KP) + (1.0 · Twon) + (1.0 · Int) + (0.05 · Pcomp)
Calculated in D3 Treemap and Packed Bubble components to ensure that all 11 players on the pitch remain visible with proportional sizing.

7.4 2D Gaussian Kernel Density Estimation (Heatmap)

Continuous Thermal Field
K(x, y) = ∑ 1 2πσ2 exp( - (x - xi)2 + (y - yi)2 2σ2 )
Rendered to offscreen canvas with kernel bandwidth σ = 6.5%. Composited directly onto the tactical pitch.
